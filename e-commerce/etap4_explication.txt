EXPLICATION DE L'ÉTAPE 4 : SÉCURITÉ ET AUTHENTIFICATION

Ce document résume la mise en place du système de sécurité sur le site.

1. L'ENTITÉ USER
----------------
Nous avons créé une table "User" dans la base de données pour stocker les comptes.
- Champs : email, password (haché), roles, et mohammed (pour le prénom).

2. INSCRIPTION (SOLID)
----------------------
Nous avons créé un formulaire d'inscription complet :
- RegistrationType : Utilise "RepeatedType" pour forcer l'utilisateur à confirmer son mot de passe.
- UserHandler (Service) : Ce service s'occupe de hacher le mot de passe avant de l'enregistrer. C'est le principe SOLID (Séparation des responsabilités).

3. CONNEXION (form_login)
-------------------------
Nous avons configuré le système d'authentification de Symfony :
- AppAuthenticator : Gère la vérification des identifiants et redirige vers l'accueil en cas de succès.
- SecurityController : Gère l'affichage du formulaire de connexion.

4. INTERFACE DYNAMIQUE
----------------------
Grâce à l'objet "app.user" dans Twig, le menu change automatiquement :
- {% if app.user %} : Affiche "Bienvenue, [Nom]" et le bouton "Déconnexion".
- {% else %} : Affiche les liens "Connexion" et "S'inscrire".

5. PROTECTION DES PAGES
-----------------------
La page Profil est sécurisée. Dans le contrôleur, nous avons ajouté :
$this->denyAccessUnlessGranted('IS_AUTHENTICATED_FULLY');
Cela empêche les utilisateurs non connectés d'accéder à leurs informations personnelles.

--------------------------------------------------
PROJET TERMINÉ : Votre site e-commerce est maintenant dynamique, sécurisé et bien structuré !
